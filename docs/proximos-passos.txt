RECEITAS PARA PROBLEMAS CONHECIDOS
═══════════════════════════════════════════════════════════════════

SICONFI rate-limit (HTTP 429 do Oracle ORDS pool):
  - Aumentar backoff em scripts/loaders/_http.py se for crônico
  - Espalhar chamadas no tempo (THROTTLE_SLEEP em siconfi.py)
  - Tentar em horários menos congestionados

CRLF warnings no git add:
  - Normais no Windows. Inofensivos. Git armazena LF, checkout para CRLF.
  - Se incomodar: git config core.autocrlf input

Pages não republica após push:
  - Aguardar 30-90s e dar ctrl+shift+R no navegador
  - Verificar Settings → Pages no GitHub se houve erro de build

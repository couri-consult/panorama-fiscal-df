RECEITAS PARA PROBLEMAS CONHECIDOS
═══════════════════════════════════════════════════════════════════

SICONFI rate-limit (HTTP 429 do Oracle ORDS pool):
  - _http.py já faz retry com backoff exponencial (até 6 tentativas)
  - siconfi.py adiciona time.sleep(3) entre chamadas
  - Cache local em .cache/http/ (TTL 6h) — re-runs ficam <10s
  - Bypass do cache: PFDF_NO_CACHE=1 antes de rodar
  - Se cair persistente: esperar 5-10 min e re-rodar

SICONFI id_ente do DF:
  - SEMPRE 53 (cod_ibge UF). NÃO usar 5300108 (Brasília município).
  - Para MT: 51. Para SP: 35. Para PI: 22.
  - Referência: Cod_instituicoes_siconfi.pdf (siconfi.tesouro.gov.br)

MCASP novo vs antigo:
  - Linha (VIII) no RREO antigo corresponde a TotalDespesas (XII)
    no SICONFI atual. Investigar mapeamento antes de assumir.

RGF Anexo 05 — cod_conta correto:
  - "DisponibilidadeDeCaixaLiquidaAposRP" (com AposRP no final)
  - Linha TOTAL: "(IV) = (I+II+III)" em 2023+, "(III) = (I+II)" em 2021-22

Portal da Transparência (FCDF scrape):
  - CloudFront WAF bloqueia UAs não-browser (HTTP 405 com captcha)
  - SEMPRE usar UA Mozilla-like para o scrape (transparencia.py já faz)
  - Para a API REST: tokens são invalidados se pedidos mais de uma vez
  - Selo gov.br Prata ou Ouro obrigatório

% Benefícios / Impostos:
  - Denominador (receita de impostos) vem do MANUAL (aba kpis linha 8)
  - SICONFI Anexo 01 NÃO traz intra-orçamentárias — proxy ruim
  - O dado correto está no RREO Anexo 8, que não tem endpoint
  - Inserir manualmente quando o RREO de fechamento for atualizado

Manual XLSX:
  - Valor monetário pode ser número em reais (auto-formata) ou string
    "R$ X bi" (preservada)
  - Sufixo entre parênteses no chave é stripado: "beneficios (R$ 1,00)"
    é tratado como "beneficios"
  - Em 'pessoal', atual_pct e rcl_bi são inseridos pelo build via upsert
    (não precisam estar na planilha)

CRLF warnings no git add:
  - Normais no Windows. Git armazena LF, checkout para CRLF.
  - Para silenciar: git config core.autocrlf input

Pages não republica após push:
  - Aguardar 30-90s e dar ctrl+shift+R no navegador
  - Verificar Settings → Pages no GitHub se houve erro de build

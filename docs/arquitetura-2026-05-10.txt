3. INTEGRAÇÃO COM GITHUB
═══════════════════════════════════════════════════════════════════

A pasta do Drive era apenas pasta sincronizada — sem git.
Hoje foi feito:
  - git init -b main na pasta do Drive
  - .gitignore com .claude/, __pycache__/, *.token, .env
  - remote origin = https://github.com/couri-consult/panorama-fiscal-df
  - git fetch + reset --mixed origin/main para alinhar com o que já estava
    publicado (index.html, data.json, panorama_fiscal_df.xlsx)
  - commit b36f72d: "Migra arquitetura..." (27 arquivos, +2100 linhas)
  - commit 692b97c: "SICONFI: corrige id_ente p/ DF estadual..."
  - git push -u origin main (autenticação via Windows Credential Manager)

A partir daqui o workflow é:
  python scripts/build_data.py
  git add data.json
  git commit -m "atualiza dados"
  git push

  RREO Anexo 01 retornou 638 linhas para o DF (2025/6º bim). Extraídos:
    - DOTAÇÃO ATUALIZADA do total de despesas: R$ 45,1 bi
    - INVESTIMENTOS LIQUIDADOS: R$ 1,8 bi
